# Session Timing Report

A turn-by-turn record of the Claude Code session that built this project: how long the agent worked
on each request, how long the human took between requests, and token use. It is generated by
`make session-log` (the script, `scripts/session_timing.py`, is from the owner's many-game-show
project and reads the session transcript under `~/.claude/projects/`). Don't edit it by hand.
